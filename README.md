# Tabby: спокойная приборная панель для Claude Code

Мод для Claude Code. Добавляет две строки над полем ввода и панель с вкладками.
За порядком следит кот Таби `(=^･ω･^=)`.

```
(=^･ω･^=)  ctx ▰▰▰▰▰▱▱▱▱▱ 48%  96k/200k  5ч ▰▱▱▱▱▱ 23%  ↻2ч14м  7д ▰▰▰▰▱▱ 67%  ↻3д4ч  $1.24   ≡
◷ ход 14 · 34с · 7 инстр  ⎇ feature/band ↑1 ✚3  ✗ 2 упало  ◎ Плашка над вводом 18м  ☐ 1/3  Починить логин
```

**Первая строка — сессия:** кот, заполнение окна контекста (проценты и токены),
лимиты подписки 5ч и 7д со временем до сброса, стоимость сессии.

**Вторая строка — работа:** текущий ход с живым таймером или последний ход,
ветка git (↑↓ относительно upstream, ✚ изменения, ✗ конфликты), статус тестов,
фокус с обратным отсчётом и мини-TODO со следующей задачей.

Плашка подстраивается под ширину: менее важные элементы уходят первыми, строки
никогда не переносятся. Цвет полос сигналит о заполнении: зелёный, жёлтый с 60%,
красный с 85%. Когда до конца контекста недалеко, появляется подсказка `⚠ /compact`.

## Панель

Открывается командой `/tab` или кнопкой `≡` в плашке. Клавиши `1`–`5` переключают
вкладки, `Esc` возвращает к вводу.

| Вкладка | Что внутри |
| --- | --- |
| **Обзор** | Крупные полосы контекста и лимитов, время до сброса, длительность сессии, ходы и инструменты, спарклайн длительности последних ходов |
| **Git** | Ветка и upstream, изменённые файлы с цветными статусами, последние коммиты, кнопка обновления (`r`) |
| **Задачи** | Фокус-помодоро (поле ввода, обратный отсчёт, `s` — завершить) и TODO-список: Enter добавляет, клик отмечает, `c` убирает выполненные |
| **Тесты** | Итог последнего прогона (сколько прошло и упало, время), команда, кнопка запуска (`t`), хвост вывода с подсветкой ошибок |
| **Таби** | Кот, уровень и опыт, 12 достижений, способ спрятать его из плашки (`p`) |

## Команды

| Команда | Что делает |
| --- | --- |
| `/tab [overview\|git\|tasks\|tests\|pet]` | Открыть панель на нужной вкладке |
| `/tab compact` | Плашка в одну строку и обратно |
| `/tab hide-pet` | Спрятать или вернуть кота |
| `/focus <цель> [минуты]` | Помодоро, по умолчанию 25 мин; `0` — без таймера; `/focus stop` — завершить |
| `/todo <текст>` · `/todo done N` · `/todo rm N` | Мини-TODO; без аргументов показывает список |
| `/test [команда]` | Запустить тесты. Команда определяется сама (npm, pnpm, yarn, bun, cargo, go, pytest, deno, mix, make); если указать свою, она запоминается для проекта |

Все команды работают и во время ответа Claude.

## Что видит Claude

- **Инструмент `mcp__tabby__todo`.** Claude может читать ваш TODO-список, добавлять
  в него пункты и отмечать выполненные. Пункты, добавленные Claude, помечены `✦`.
- **Цель фокуса и открытые задачи.** Они коротко добавляются к вашему сообщению,
  только когда изменились. Системный промпт не трогается, кеш промпта не сбрасывается.
- **Тесты.** Когда Claude сам запускает тесты через Bash (`npm test`, `pytest`,
  `cargo test`…), результат тоже попадает в плашку.

## Уведомления

Короткие тосты появляются, только когда это важно:

- контекст заполнен на 80% или 90%;
- лимит 5ч или 7д израсходован на 80% или 95%;
- закончилось помодоро;
- ход шёл дольше 90 секунд;
- тесты упали или снова стали зелёными;
- новое достижение или уровень Таби.

## Таби

Настроение кота отражает сессию: мурлычет, помогает во время хода, грустит
при красных тестах, сосредоточен в фокусе, засыпает после 15 минут простоя,
гордится после нового достижения. Опыт копится за ходы (+2), зелёные тесты (+10),
закрытые задачи (+3), помодоро (+8) и достижения (+15). Прогресс сохраняется
между сессиями.

## Установка

```bash
git clone https://github.com/alexskvo10/claude-tab
claude --plugin-dir ./claude-tab
```

Можно подключать постоянно: впишите абсолютный путь в `CLAUDE_CODE_PLUGIN_DIRS`
(переменная окружения или блок `env` в `~/.claude/settings.json`).

Мод использует function hooks Claude Code (early access, сборка 2.1.289+).

## Разработка

```bash
claude plugin validate .   # манифест и модуль хуков глазами движка
claude plugin test .       # 29 тестов: утилиты, плашка, панель, команды, инструмент
tsc -p .                   # после первой загрузки движок кладёт типы в .claude-plugin/types/
```

Структура:

```
hooks/register.tsx   хуки, команды, инструмент; единственное место, где есть `$`
hooks/actions.ts     вся логика изменения состояния (git, тесты, задачи, фокус, кот)
hooks/ui/            отрисовка плашки и панели — чистые функции от снимка состояния
hooks/lib/           форматирование, разбор git и вывода тестов, раскладка, кот
types/index.d.ts     контракт состояния ($.state)
tests/               тесты для `claude plugin test`
```
